Installer Ink Lab dans PowerPoint

Une commande à coller, puis on relance PowerPoint. Aucun fichier à télécharger. Mac, PowerPoint Microsoft 365.

1

Copie la commande

mkdir -p ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef && curl -fsSL https://gvsxx.github.io/ink-lab-powerpoint/manifest.xml -o ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef/inklab.xml && echo "Ink Lab est installé. Relance PowerPoint."
2

Colle-la dans le Terminal

Ouvre Terminal (Cmd + Espace, tape « Terminal »), colle avec Cmd + V et appuie sur Entrée. Si macOS demande l'accès aux données d'autres apps, clique sur Autoriser.

3

Relance PowerPoint

Quitte-le avec Cmd + Q, rouvre-le : le bouton Ink Lab est dans l'onglet Accueil. Sinon : Insertion › Compléments › Mes compléments.

Les mises à jour d'Ink Lab arrivent toutes seules : il n'y a rien à réinstaller. La version navigateur est ici : Ink Lab web.
